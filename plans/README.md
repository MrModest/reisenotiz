# plans/

Feature plans and PRDs.

- **`archived/`** — delivered or abandoned plans, kept as a record of the decisions behind
  shipped code. **Treat these as history, not as current state**: they describe the codebase as
  it was when the plan was written, and each carries a status banner saying so.
- **Live plans** sit directly in `plans/`. There are none right now.

For what the code looks like *today*, read `CLAUDE.md`, `apps/frontend/CLAUDE.md` and
`docs/agents/`. When a plan and the code disagree, the code wins.
